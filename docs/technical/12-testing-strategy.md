# Kazi — Testing Strategy

## Tests manuels
Fonctionnalité, console, responsive, clavier, focus, liens.

## Viewports
320, 375, 768, 1024, 1280, 1440+ et un vrai téléphone.

## Static checks
Lint, TypeScript, build.

## Accessibility
Clavier, focus, contraste, alt, headings, boutons/liens, menu, accordion, reduced motion.

Les tests automatisés seront ajoutés lorsqu'ils apportent une valeur réelle ; pas d'infrastructure lourde sans besoin.
