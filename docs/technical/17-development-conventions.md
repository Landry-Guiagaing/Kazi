# Kazi — Development Conventions

## Naming
Components : PascalCase. Variables/functions : camelCase. Data files : camelCase.

## React
Client Component uniquement si nécessaire. Éviter le state global prématuré.

## HTML
button = action, a = navigation, nav = navigation, main = contenu principal, section = zone identifiable.

## Tailwind
Utiliser les tokens et éviter les valeurs arbitraires répétées.

## Comments
Expliquer pourquoi, pas ce que le code fait.

## Git
Exemples : feat(hero): add hero section ; fix(header): prevent overflow ; docs(scope): define V1.
