# Kazi — Technical Specification

## Stack
Next.js, React, TypeScript, Tailwind CSS, Lucide React.

## Reporté
Framer Motion et shadcn/ui ne sont pas nécessaires au démarrage.

## Fonts
Playfair Display pour les titres, Inter pour le corps, via next/font.

## Data
Données locales typées dans data/.

## State
State React local pour menu, accordion et éventuel carousel.

## Principes
TypeScript strict, pas de any inutile, composants à responsabilités claires, HTML sémantique, dépendances ajoutées uniquement pour résoudre un besoin réel.
