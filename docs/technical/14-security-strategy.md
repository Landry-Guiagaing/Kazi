# Kazi — Security Strategy

## V1
Pas d'authentification, données privées, backend, paiement ou upload utilisateur.

## Règles
Ne jamais committer de secrets. Ne pas mettre de clés privées côté client. Ne pas utiliser de vraies données personnelles dans les données de démonstration.

## Futur
Le backend devra traiter auth, autorisation, validation serveur, sanitation, uploads, rate limiting, secrets, logs et protection des données.
