# Kazi — Architecture

## V1
Browser → Next.js App Router → Pages/Layout → Sections/UI Components → Local Typed Data → Static Assets.

## Futur
Browser → Next.js → API → Auth / Users / Talents / Companies / Opportunities / Matching → Database.

## Principes
Separation of concerns, réutilisation raisonnable, simplicité V1, évolution progressive et remplacement futur des données locales par une API sans réécriture globale.
