# Kazi — Typography System V1

**Version:** 1.0  
**Statut:** Validé pour implémentation

## 1. Familles

### Headings
**Playfair Display**

Utilisation :
- H1
- H2
- H3
- titres éditoriaux importants

Rôle : élégance, personnalité, prestige.

### Interface et contenu
**Inter**

Utilisation :
- paragraphes
- navigation
- boutons
- labels
- formulaires
- informations secondaires

Rôle : lisibilité, neutralité, modernité.

## 2. Hiérarchie

| Niveau | Desktop | Mobile | Weight | Line-height |
|---|---:|---:|---:|---:|
| H1 | 64px | 36px | 600–700 | 1.05–1.15 |
| H2 | 48px | 30px | 600–700 | 1.10–1.20 |
| H3 | 36px | 26px | 600 | 1.15–1.25 |
| H4 | 28px | 22px | 600 | 1.20–1.30 |
| H5 | 22px | 20px | 600 | 1.25–1.35 |
| H6 | 18px | 18px | 600 | 1.30–1.40 |

Ces tailles sont une base de Design System et pourront être ajustées lors de l'implémentation visuelle.

## 3. Body

- Body large : 18px / 1.6
- Body : 16px / 1.6
- Small : 14px / 1.5
- Caption : 12–13px / 1.4
- Labels : 14px / 1.4

Le texte courant ne doit pas descendre sous 16px sans justification.

## 4. Poids

Inter :
- 400 : normal
- 500 : medium
- 600 : semibold
- 700 : bold

Playfair Display :
- 500–700 selon le niveau.

## 5. Letter spacing

Le letter-spacing doit rester discret.

Les grands titres peuvent utiliser un léger resserrement si nécessaire.

Les petits labels en uppercase peuvent utiliser un espacement légèrement positif.

## 6. Règles

- Un seul H1 par page.
- La hiérarchie des headings doit être logique.
- Ne pas utiliser une taille de police uniquement pour imiter un heading.
- Les paragraphes doivent rester lisibles.
- Les textes ne doivent pas être transformés en éléments graphiques au détriment de l'accessibilité.
