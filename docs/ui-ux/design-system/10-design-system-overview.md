## Règle fondamentale

Une décision de design doit pouvoir être justifiée par :
- la lisibilité
- la hiérarchie
- l'accessibilité
- la cohérence
- le besoin utilisateur
- la maintenabilité

Pas simplement par une préférence esthétique.
