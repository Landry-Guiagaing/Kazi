## Functional Requirements
| ID | Exigence | Priorité |
|---|---|---|
| FR-001 | Navigation principale fonctionnelle | Must |
| FR-002 | Menu mobile ouvrable/fermeture | Must |
| FR-003 | Hero avec proposition de valeur et CTA | Must |
| FR-004 | Talents mis en avant | Must |
| FR-005 | Catégories | Must |
| FR-006 | Comment ça marche | Must |
| FR-007 | Bénéfices talent/entreprise | Must |

## Non-functional
Responsive 320px+, WCAG 2.1 AA, performance raisonnable, maintenabilité, navigateurs modernes, SEO de base, reduced motion.

## Acceptance
Une exigence est satisfaite lorsqu'elle est implémentée, testée, accessible et sans régression.
