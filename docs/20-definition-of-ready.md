# Kazi — Definition of Ready

Une tâche est Ready lorsque :
- objectif clair ;
- périmètre défini ;
- résultat attendu ;
- critères d'acceptation ;
- données nécessaires connues ;
- responsive défini ;
- états interactifs définis ;
- dépendances connues ;
- aucune ambiguïté critique.

Exemple TalentCard : nom, spécialité, image, description, catégorie, CTA, responsive, hover/focus et alt doivent être connus avant développement.
